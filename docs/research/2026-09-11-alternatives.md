# Alternatives à Voice Meets

Recherche effectuée le 11 septembre 2026. Sources officielles uniquement : dépôts, tarifs et documentation des éditeurs. Tarifs conservés dans leur devise d'affichage, sans conversion CHF ni estimation fiscale. Les pages peuvent évoluer ; certaines descriptions commerciales et README sont en décalage. Aucun produit n'a été testé pendant cette recherche.

## Conclusion

Le marché existe déjà, y compris en open source et avec le modèle « gratuit local/BYOK, cloud payant ». Anarlog est particulièrement proche de cette proposition. L'opportunité à valider pour Voice Meets est le parcours **discussion + écran → note horodatée → passage vidéo ambigu → précision humaine → note actualisée**, avec une interface simple. Ce positionnement est une hypothèse différenciante, pas une affirmation d'exclusivité.

## Décisions proposées

1. Livrer d'abord une session nommée, la bibliothèque locale, une capture explicite, puis l'analyse OpenAI après arrêt.
2. Conserver des segments de média localement et une chronologie commune aux images, transcription et notes.
3. Identifier les corrections humaines et préserver la transcription originale ; fournir des liens vers les passages.
4. Mesurer le coût réel par heure et le taux de notes corrigées avant de fixer les quotas d'un abonnement.
5. S'inspirer des parcours des concurrents plutôt que reprendre un monorepo Rust/Tauri incompatible avec notre choix TypeScript/Electron. Aucun besoin d'OAuth dans ce MVP.

Les liens ci-dessus établissent les capacités et limites mentionnées, pas une évaluation comparative de qualité. Cette recherche ne démontre ni l'absence d'autres concurrents ni l'unicité du parcours de clarification vidéo.

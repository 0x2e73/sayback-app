## A. Thème clair

### A1. Une seule source : `nativeTheme.themeSource`

Pas de `data-theme` dans le renderer. Le main règle `nativeTheme.themeSource` sur `'system' | 'light' | 'dark'` et Chromium aligne `prefers-color-scheme` dessus. Un seul interrupteur fait basculer ensemble le CSS, le matériau vibrancy, les barres de défilement, les `<select>` natifs, les menus et les dialogues système.

```
:root { color-scheme: light dark; …valeurs claires… }
@media (prefers-color-scheme: dark) { :root { …couleurs sombres + --shadow-float… } }
@media (prefers-contrast: more) { :root { …renforts clairs… } }
@media (prefers-contrast: more) and (prefers-color-scheme: dark) { :root { …renforts sombres actuels… } }
:root[data-platform='mac'] { … }   /* inchangé */
:root[data-fullscreen] { … }       /* inchangé */
```

Les `*-tint`, `--color-danger-line` et `--color-accent-soft` sont des `color-mix` déclarés une fois : ils se recalculent depuis la couleur du thème.

Le choix n'arrive pas au renderer comme thème : le renderer lit `settings.appearance` pour afficher le contrôle et appelle `api.setAppearance(v)`. Le main enregistre et règle `themeSource`. Le CSS bascule seul.

## B. Passe de motion

| Token                                 | Valeur                           | Usage                                                       |
| ------------------------------------- | -------------------------------- | ----------------------------------------------------------- |
| `--duration-fast`                     | 120ms                            | Couleurs au survol, appui                                   |
| `--duration-exit`                     | 150ms                            | Toutes les sorties, plus rapides que les entrées            |
| `--duration-base`                     | 200ms                            | Entrées de petits éléments                                  |

| `--delay-wait`                        | 300ms                            | N'affiche un chargement que s'il dure                       |
| `--ease-out`                          | `cubic-bezier(0.23, 1, 0.32, 1)` | Entrées, sorties, couleurs                                  |

| `--ease-linear`                       | `linear`                         | Boucles, progression                                        |
| `--ease-ambient`                      | `cubic-bezier(0.37, 0, 0.63, 1)` | Boucles lentes seulement                                    |
| `--motion-rise`                       | 6px                              | Arrivée de contenu                                          |
| `--motion-drop`                       | -4px                             | Menus qui descendent de leur déclencheur                    |
| `--motion-slide`                      | 8px                              | Changement d'onglet, dans le sens du segmenté               |
| `--motion-scale-in`                   | 0.96                             | Entrée des dialogues et pastilles                           |
| `--motion-scale-out`                  | 0.98                             | Sorties, couche de sélection, ligne glissée                 |
| `--motion-press`                      | 0.97                             | Appui                                                       |
| `--motion-icon`                       | 0.5                              | Échange d'icônes                                            |
| `--motion-accept`                     | 1.06                             | Pastille qui reçoit une réunion déposée                     |

Pas de vrai ressort : le seul geste est un glisser-déposer HTML natif, sans vitesse à transmettre.

Mouvement réduit = changer des tokens : le bloc `prefers-reduced-motion` remet les `--motion-*` à `0px` ou `1` et les `--delay-*` à `0ms`, coupe les boucles et l'indicateur qui glisse. Toutes les entrées deviennent des fondus.

### B2. Mécanique commune

| Besoin                                 | Outil                                                                                               | Raison                                                                                                                                                                                                                                                       |
| -------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Entrée au montage, onglet qui apparaît | Transition avec `@starting-style`                                                                   | Interruptible ; la même déclaration sert à la sortie                                                                                                                                                                                                         |
| Sortie                                 | `components/use-presence.ts` : `usePresence(open)` → `{ mounted, state: 'open' \| 'closing', ref }` | `data-state="closing"` et `pointer-events: none`, démonte au `transitionend` (opacity, cible = l'élément), filet de sécurité de 400 ms, démontage immédiat si `transitionDuration` vaut `0s` (jsdom). Une réouverture pendant la fermeture repasse en `open` |
| `@keyframes`                           | Seulement `spin`, `skeleton-pulse`, `turn-target`, `chip-accept`, dans `styles.css`                 | Séquences jouées une fois ou en boucle                                                                                                                                                                                                                       |

### B5. Règle du garde `motion-guard.test.ts`

1. Tokens déclarés : exactement `--duration-{fast,exit,base,slow,loop,ambient}`, `--delay-{1,2,3,wait}`, `--ease-{out,move,linear,ambient}`.
2. `transition*` et `animation*` n'utilisent que ces `var()` : pas de temps en dur, pas de mot-clé ni de fonction d'easing, pas de `calc`.
3. Propriétés animées : `opacity`, `transform`, `background-color`, `border-color`, `color`, `outline-color` ; les corps de `@keyframes` sont analysés avec la même liste blanche.
4. `--duration-*` ≤ 300 ms sauf `loop` et `ambient` ; `--duration-exit` < `--duration-base`.
5. `infinite` seulement avec `--duration-loop` ou `--duration-ambient`, et chaque sélecteur concerné a `animation: none` dans le bloc mouvement réduit.
6. Toute règle `[data-state='closing']` qui pose une durée utilise `--duration-exit`.
7. Le bloc mouvement réduit remet chaque `--motion-*` à `0px` ou `1` et chaque `--delay-1..3` à `0ms`.
8. `scroll-behavior: smooth` interdit partout.
9. `@keyframes` et `prefers-reduced-motion` seulement dans `styles.css`.

# Voice Meets MVP Implementation Plan

**Goal:** Local desktop capture and meeting notes.

**Architecture:** Clean backend behind typed Electron IPC, React UI, SQLite/local media, OpenAI adapter.

**Tech stack:** TypeScript, Electron, electron-vite, React, SQLite, Zod, OpenAI, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-11-mvp-design.md`

## Constraints

No OAuth, hosted secrets or cloud synchronization. Accessible reusable UI. Preserve recordings and corrections. Execute inline in TDD cycles.

## Tasks

- [ ] Backend: failing lifecycle, persistence, retry and correction tests; implement entities, ports, SQLite and MeetingService; run targeted tests.
- [ ] Provider: failing transcription and cited-notes contract tests; implement injected OpenAI adapter; validate schemas and references.
- [ ] Desktop: failing boundary tests; main composition, encrypted credentials, validated IPC, media protocol, preload.
- [ ] Frontend: failing user-flow and capture tests; shared UI, library, settings, recording and meeting detail.
- [ ] Verification: strict types, lint, tests, build, UI inspection and local packaging; document live API and platform limits.
